# Project Statement

## Project Title
**Cosmic Dodge – A Python Space Dodge Game**

## Description

Cosmic Dodge is a simple 2D arcade game developed using Python and Pygame. The player controls a character at the bottom of the screen and must avoid falling stars.

The main goal is to survive for as long as possible without getting hit by a falling star.

## Objectives

- Create a playable game using Python.
- Use Pygame for graphics and game controls.
- Implement player movement using the keyboard.
- Generate falling stars at random positions.
- Detect collisions between the player and stars.
- Display the survival time.
- Increase the difficulty as the game progresses.

## How It Works

The player can move left and right using the arrow keys. Stars are randomly generated above the screen and fall downward.

If a star hits the player, a collision occurs and the game ends. The player's survival time is displayed on the screen.

As time passes, stars appear more frequently, making the game more challenging.

## Technologies Used

- Python 3
- Pygame

## Python Concepts Used

- Variables
- Functions
- Loops
- Conditional statements
- Lists
- Random number generation
- Keyboard input
- Collision detection
- Time management

## Controls

| Key | Action |
|---|---|
| Left Arrow | Move Left |
| Right Arrow | Move Right |
| Close Button | Exit Game |

## Expected Outcome

The final program provides a simple and interactive game where the player tries to survive as long as possible while avoiding falling stars.

## Conclusion

Cosmic Dodge demonstrates the use of basic Python programming concepts and the Pygame library to create an interactive arcade game.
